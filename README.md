# NetMessenger

## Overview

NetMessenger is a TCP-based client-server messaging application developed for the Network Programming assignment.

The project demonstrates network communication using C socket programming and supports communication between a server and multiple clients.

## Technologies Used

- C Programming
- TCP/IP
- Socket Programming
- Linux / CentOS
- `fork()`
- Makefile
- Git and GitHub
